# 💕 Aplicación del Día de San Valentín - Para mi esposa bella

Una aplicación web especial creada con amor para mi esposa, una psiquiatra extraordinaria.

## 🌟 Características

- **Generador de Razones de Amor**: 30 razones únicas que combinan:
  - Ingeniería y tecnología 💻
  - Psiquiatría y ciencia de la mente 🧠
  - 18 años de historia juntos 💑
  - Nuestros 3 hijos hermosos 👨‍👩‍👧‍👦
  - Fe y comunidad cristiana ✝️

- **Exportar Receta Médica**: Genera una prescripción médica en PDF firmada por "Dr. Jafeth", con dosis de amor, besos y abrazos.

- **Diseño Hermoso**:
  - UI minimalista con gradientes suaves (rosa, púrpura)
  - Tipografía Serif elegante
  - Animaciones fluidas con Framer Motion
  - Mobile-first y totalmente responsivo

- **Mensaje de Fe**: Footer con "Ánimo, ¡Cristo ha resucitado! ✝️"

## 🛠️ Tecnologías

- React 19 + TypeScript
- Vite (build tool)
- Tailwind CSS v4
- Framer Motion (animaciones)
- jsPDF (generación de PDF)

## 🚀 Uso

```bash
# Instalar dependencias
npm install

# Ejecutar en modo desarrollo
npm run dev

# Construir para producción
npm run build

# Vista previa de la build
npm run preview
```

## 📝 Estructura

Todo el código de la aplicación está contenido en un solo archivo: `src/App.tsx`

## Valentine's Day Love App

A beautiful web application created for Valentine's Day with personalized love messages, animations, and PDF export functionality.

### Features

- 15 personalized love reasons with tech/faith metaphors
- Smooth animations using Framer Motion (fade/scale transitions)
- Random reason generator
- PDF export in medical prescription format
- Beautiful gradient background (rose to teal)
- Elegant serif typography (Playfair Display & Crimson Text)

### Tech Stack

- React 19
- TypeScript
- Vite
- Tailwind CSS
- Framer Motion
- jsPDF

### Development

```bash
npm install
npm run dev
```

### Build

```bash
npm run build
```

### Preview

```bash

```
