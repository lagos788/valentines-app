## Valentine's Day Love App

A beautiful web application created for Valentine's Day with personalized love messages, animations, and PDF export functionality.

### Features

- 15 personalized love reasons with tech/faith metaphors
- Smooth animations using Framer Motion (fade/scale transitions)
- Random reason generator
- PDF export in medical prescription format
- Beautiful gradient background (rose to teal)
- Elegant serif typography (Playfair Display & Crimson Text)

### Tech Stack

- React 19
- TypeScript
- Vite
- Tailwind CSS
- Framer Motion
- jsPDF
